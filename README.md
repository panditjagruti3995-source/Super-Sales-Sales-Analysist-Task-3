# Super-Sales-Sales-Analysist-Task-3
Advanced SQL analysis, KPI modeling, and an executive Power BI dashboard for SuperStore sales data — Task 3 of the Data Analytics &amp; BI internship at Maincrafts Technology.

## Objective
Perform advanced SQL queries, variance and growth analysis, and build 
an executive-level BI dashboard to support strategic decision-making.

## Contents
- `01_SQL_Analysis.sql` — CASE statements, subqueries, HAVING clause queries
- `02_Excel_Variance_Analysis.xlsx` — Variance & growth % calculations
- `03_PowerBI_Dashboard.pbix` — Interactive executive dashboard
- `04_Dashboard_Screenshot.png` — Dashboard preview
- `05_Business_Recommendation_Report.pdf` — Strategic insights & recommendations

## Key Insights
- Total Sales: 2.30M | Total Profit: 286.41K | Profit Margin: 12.47%
- Growth %: 47% (month-over-month, Q4-driven)
- South region underperforming vs. West, East, Central
- Consumer segment contributes 51% of total revenue
